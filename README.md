# X4 Mod Launcher

Production distribution for the X4 Foundations Mod Launcher.

## Run

1. Keep `Launch-X4ModLauncher.cmd` beside the `X4ModLauncher` folder.
2. Run `Launch-X4ModLauncher.cmd`.

The launcher executable and all required runtime files are kept together in
`X4ModLauncher`. The ZIP release contains this same production layout.

Download the packaged release from the [Releases page](https://github.com/Alakeram/x4-mod-launcher/releases).
