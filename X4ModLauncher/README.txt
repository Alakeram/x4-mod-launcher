X4 Mod Launcher
Nexus Mods distribution package

Installation
1. Extract the entire ZIP to a normal writable folder.
2. Keep X4ModLauncher.exe together with all of the DLL and runtime files in this folder.
3. Run X4ModLauncher.exe.

Requirements
- Windows 10/11 64-bit
- X4: Foundations installed separately
- X4 must be closed before applying profile changes or restoring a backup

This package contains the launcher only. It does not include X4, DLC, saves, or third-party extensions.

The launcher is local-only: it does not download files, upload profile data, use telemetry, or auto-update itself.

If Windows or an antivirus product reports a false positive, use the published SHA-256 hash and the project source to verify the package. Do not disable Windows security features.
